# Public API snapshots

One file per published library crate and feature combination, generated by
`cargo public-api -ss` (blanket and auto-trait impls omitted) so that every
change to the public surface shows up as a diff in review.

**A snapshot is review evidence, not a proof of behaviour.** It shows which
names and signatures exist. Semantics, layouts, errors, resource costs and
numerical results are checked by tests.

**`#[doc(hidden)]` items are included.** The script has rustdoc document hidden
items (`--document-hidden-items`), so crate seams such as `__network` and
hidden methods are listed alongside documented items, without a marker.

## Files and feature combinations

The combinations are fixed in `scripts/api-snapshot.sh`; change the script and
this table together.

| File | Crate | Features |
|---|---|---|
| `<crate>.txt` | every crate below | default features |
| `symtn-sectors+all.txt` | `symtn-sectors` | `cgc-gen,testing` |
| `symtn-core+all.txt` | `symtn-core` | `cgc-gen,testing` |
| `symtn-dense+all.txt` | `symtn-dense` | default + `cuda` |
| `symtn-operations+all.txt` | `symtn-operations` | default + `cuda,testing` |
| `symtn-tensors+all.txt` | `symtn-tensors` | default + `cuda,cgc-gen,testing` |
| `symtn-matrixalgebra+all.txt` | `symtn-matrixalgebra` | default + `cgc-gen` |
| `symtn+all.txt` | `symtn` | default + `cuda,cgc-gen,krylov` |
| `symtn-network+all.txt` | `symtn-network` | default + `cuda,cgc-gen,opt-path,cotengra-python` |

The `+all` file of a crate enables every additive feature that widens its
public surface, including the unstable `testing` tiers: they are reachable by
any dependent that enables them, so their items are reviewed too.

Not snapshotted:

- `publish = false` packages (`tests/production-contract`).
- `symtn-macros`: a proc-macro crate, for which rustdoc emits no JSON. Its
  `contract!` macro is re-exported by `symtn-network` and appears there.
- BLAS-provider features (`cpu-blas`, `blas-*`, `provider-inject`): they select
  a backend implementation of the same surface.
- `symtn/ledger-roots`: it only switches on a dependency's ledger and adds no
  symtn item.

## Updating

```bash
scripts/api-snapshot.sh --write   # regenerate api/*.txt
git diff api/                     # review: removed and added items
scripts/api-snapshot.sh --check   # what CI runs (lint job)
```

Commit the regenerated files in the same change as the code. A pull request
that changes the public API without updating `api/` fails the `lint` job.

The tool needs `cargo-public-api` 0.52.0 and the nightly pinned in the script
(`nightly-2026-09-19`), for rustdoc JSON; CI installs both. If a nightly update
changes the rendering without an API change, re-pin the script and CI together
and regenerate.
